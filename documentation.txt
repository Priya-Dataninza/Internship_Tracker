Golden Rules to Keep in MindKeep these conceptual invariants in mind whenever you add new endpoints or forms to your Django project:Local Storage is a Local Clock: The frontend JavaScript reads the Access Token to monitor the time, but it uses the Refresh Token as the actual currency passed to the backend server to purchase a new token chain.Natural Expiration != Fraud: If a user closes their browser for 2 weeks, their refresh token expires naturally over time (TokenError). This does not trigger the security alarm or alter token_version. It simply pushes them to the login screen safely.The InvalidToken Exception is Sacred: The custom view code inside except InvalidToken: only triggers if the system attempts to process an identical token string that has already been registered in the database blacklist. This represents an explicit data reuse signature.The Border Guard Rule: You do not need to hunt down the hacker's computer or wipe their memory storage fields. By incrementing user.token_version on your backend server, you change the lock at the server border.
